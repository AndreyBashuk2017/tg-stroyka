# Brief: Telegram Mini App — Калькулятор строительства дома

> Документ для разработки. Описывает каждый экран, элементы, действия и переходы.  
> Стек: React + Vite · Хостинг: Netlify · Язык интерфейса: русский

---

## Принципы дизайна

| Принцип | Как реализуем |
|---|---|
| Нативный Telegram | Цвета из `themeParams`, никакого белого фона поверх тёмной темы |
| Мобильный первый | Всё проектируем под 390px (iPhone 14), не под десктоп |
| Крупные кнопки | Минимум 44px высота, лучше 56px — чтобы попасть большим пальцем |
| Минимум текста | Иконка + 1–2 слова. Никаких абзацев на экранах выбора |
| Максимум визуала | Карточки с картинками, иконками, цветовыми акцентами |
| Это приложение | Нет хедера сайта, нет навигационного меню, нет ссылок |
| Один экран — одно действие | Пользователь не думает что делать |

---

## Архитектура переходов

```
[Старт]
   ↓ MainButton «Начать расчёт»
[Шаг 1: Площадь + этажность]
   ↓ MainButton «Далее»
[Шаг 2: Фундамент]
   ↓ MainButton «Далее»
[Шаг 3: Кровля]
   ↓ MainButton «Далее»  ← здесь появляется предварительная цена
[Шаг 4: Стиль]
   ↓ MainButton «Далее»
[Шаг 5: Отделка]
   ↓ MainButton «Далее»
[Шаг 6: Опции]
   ↓ MainButton «Рассчитать»
[Результат]
   ↓ MainButton «Узнать точную стоимость»   → [Форма контакта]
   ↓ Кнопка «Поделиться»                    → Telegram share
[Форма контакта]
   ↓ MainButton «Отправить»
[Спасибо]

← BackButton Telegram работает на каждом шаге 2–6 и на форме
```

### Экран 0 — Старт

**Что видит пользователь:**
- Логотип / название компании (крупно, по центру)
- Одна строка подзаголовка
- Иллюстрация дома или фото готового объекта (занимает ~40% экрана)
- Один блок доверия (например: «40 домов построено»)

**Элементы:**
```
┌─────────────────────────────────┐
│                                 │
│        [логотип компании]       │
```

## Чего НЕ будет в первой версии (v1)

| Что | Почему не сейчас |
|---|---|
| Каркасный / брусовый / кирпичный дом | Сначала проверяем одну нишу |
| Личный кабинет / история расчётов | Лишняя сложность для MVP |
| Сравнение двух конфигураций | После валидации спроса |
| PDF-смета | Нужен backend для генерации |
| Ипотечный калькулятор с выбором программы | Достаточно простого расчёта |
| Анимации и Lottie | Скорость важнее красоты |
| 3D-визуализация дома | Слишком долго |
| Трекинг хода строительства | Отдельный продукт |
| Админ-панель | Цены меняем через GitHub |
| Google Sheets / CRM | Telegram уведомления достаточно |
| Онлайн-оплата | Не нужно для MVP |
| Каталог проектов | В следующей итерации |
