## Executive Summary

Telegram Mini App для строительной компании (Калужская / Московская обл.), специализирующейся на домах из газобетона. Пользователь — частный застройщик — настраивает параметры будущего дома, мгновенно видит ориентировочную стоимость с разбивкой по этапам, затем по желанию оставляет контакт. Лид автоматически приходит в Telegram-чат менеджера. MVP строится за 1–3 дня методом вайбкодинга (React + Vite + AI-ассистент).

---

## Проблема и цель

**Боль клиента:** Хочет узнать цену дома прямо сейчас, без звонков и «мы перезвоним». Конкуренты прячут цену за заявкой.  
**Боль компании:** Лиды из Telegram-канала обрабатываются вручную, нет автоматизации.

**Решение:** Дать честный расчёт до запроса контакта → заработать доверие → получить тёплый лид.

**Метрика успеха MVP:** ≥ 5 входящих лидов в неделю через Mini App.

## Пользовательский путь (Happy Path)

```
1. Пользователь находит бота (через рекламу / Telegram-канал / ссылку)
2. Нажимает кнопку «Рассчитать стоимость» → открывается Mini App
3. Проходит 6 шагов квиза (см. ниже) ← выбор карточками, не текстом
4. На шаге 3 видит промежуточную цену «ориентировочно от X млн ₽»
5. После шага 6 — экран результата с разбивкой по статьям + итог
6. Нажимает «Узнать точную стоимость» → форма (имя + телефон)
7. Лид уходит в Telegram-чат менеджера
8. Экран «Спасибо» — менеджер позвонит в течение 2 часов
```

## Экраны и шаги калькулятора

### Шаг 0: Стартовый экран
- Логотип компании / название
- Оффер: *«Узнайте стоимость вашего дома из газобетона — за 2 минуты, без звонков»*
- Кнопка «Рассчитать» (MainButton)
- Доверие: кол-во построенных объектов / регионы работы

### Шаг 1: Площадь и этажность
- Слайдер площади: 60–300 м² (шаг 10 м²) + ручной ввод
- Карточки этажности: 1 этаж / 1.5 (с мансардой) / 2 этажа
- Хинт: «120 м² — это одноэтажный 10×12 или двухэтажный 8×8»

### Шаг 2: Тип фундамента
Карточки с иконкой + подсказкой «когда подходит»:
- 🔩 Свайно-винтовой *(быстро, подходит для большинства участков)*
- ▭ Ленточный *(классика, надёжно)*
- ⬜ Монолитная плита *(максимальная надёжность)*
- 🏠 УШП — утеплённая шведская плита *(тёплые полы, премиум)*

### Шаг 3: Кровля
**Материал (карточки):**
- Металлочерепица *(бюджетно, популярно)*
- Мягкая черепица *(тихо, долговечно)*
- Фальцевая *(премиум, современно)*

**Форма (карточки):**
- Двускатная / Четырёхскатная / Плоская

> 💡 После шага 3 — показать промежуточный итог: «Ориентировочно **от X млн ₽**»

### Шаг 4: Архитектурный стиль
Карточки с **фото/рендером** дома + коэффициент стоимости:
- 🏡 Классика *(традиционный фасад)* — базовая цена
- ⬛ Хай-тек *(панорамные окна, плоская / низкая кровля)* — +10%
- 🏔 Шале *(крутая кровля, балкон, деревянные акценты)* — +18%

### Шаг 5: Уровень отделки
Карточки:
- 🏗 Коробка *(только стены + кровля, без отделки)*
- 🔨 Черновая *(стяжка, штукатурка, разводка)*
- 🏠 Под ключ Эконом *(бюджетные материалы)*
- ✨ Под ключ Стандарт *(современные материалы)*

### Шаг 6: Дополнительные опции
Мультивыбор чекбоксами:
- [ ] Терраса *(+N ₽)*
- [ ] Гараж на 1 автомобиль *(+N ₽)*
- [ ] Баня/сауна *(+N ₽)*

## Формула расчёта

```typescript
// calculator.ts
function calculate(params: CalcParams): CalcResult {
  const { area, floors, foundation, roofMaterial, roofShape,
          style, finishing, options } = params;

  // 1. Базовая стоимость коробки
  const boxCost = area * PRICES.boxPerSqm[floors];

  // 2. Фундамент (надбавка на м² площади)
  const foundationCost = area * PRICES.foundation[foundation];

  // 3. Кровля (коэффициент от коробки)
  const roofCost = boxCost
    * (PRICES.roofMaterial[roofMaterial] - 1)
    + boxCost * (PRICES.roofShape[roofShape] - 1);

  // 4. Стиль (коэффициент на сумму конструктива)
  const structural = boxCost + foundationCost + roofCost;
  const styleSurcharge = structural * (PRICES.style[style] - 1);

  // 5. Отделка
  const finishingCost = area * PRICES.finishing[finishing];

  // 6. Опции
  const optionsCost = options.reduce(
    (sum, opt) => sum + PRICES.options[opt], 0
  );

  const total = structural + styleSurcharge + finishingCost + optionsCost;

  return {
    breakdown: {
      foundation: foundationCost,
      box: boxCost,
      roof: boxCost * PRICES.roofMaterial[roofMaterial] * PRICES.roofShape[roofShape] - boxCost,
      style: styleSurcharge,
      finishing: finishingCost,
      options: optionsCost,
    },
    total,
    perSqm: Math.round(total / area),
    mortgage: Math.round(total * 0.06 / 12 / (1 - Math.pow(1 + 0.06/12, -240))),
  };
}
```
